# Parallel Lines: Geometry Study Guide

A study site for Geometry Unit 2. It has two sections:

- **Learn**: the big idea (only two angle sizes), an interactive angle-pair explorer, every angle pair with its theorem and converse, kinds of lines, five worked solve-for-x examples, the reasons used in two-column proofs, three worked proofs you reveal one step at a time, conditional statements and the laws of logic, and key words.
- **Practice test**: about 100 questions on angle pairs, solving for x (typed answers), proofs and reasons, logic, and angle basics. Diagrams and numbers change every time.

It's a single self-contained `index.html`. All diagrams are drawn by code in the page. Open it in any browser, or publish it with GitHub Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
